# Asterion Control — owner intelligence directive, 2026-11-26
Status: **owner-directed requirements**, not implementation or acceptance evidence.
Source: owner's "INDEPENDENT, OWNER-TAILORED INTELLIGENCE" directive, Nov 26, 2026.
Authority: newer owner correction takes precedence where a previous model size,
training priority or hardware assumption conflicts. All nonconflicting V3–V6,
Nexus/December, Model Laboratory, Skill Studio and approved application requirements
remain mandatory. This file is a decision-source transcription, not a replacement
for complete conversations, original PDFs or historical specifications.

## OAI-01 Absolute quality objective
The target is a genuinely capable, independent, owner-adapted, progressively
improving general intelligence on Samsung SM-S948B Android 17. It should eventually
replace ChatGPT across ordinary and Asterion usage. Model size, a successful sample,
a generic prompt, an agent wrapper, and compilation are not acceptance.

## OAI-02 Stronger neural candidates
There is no arbitrary 2–4B ceiling. Investigate 7B, 8B, 12B, 14B and larger
dense/MoE/hybrid/SSM/recurrent candidates. Compare model-native reasoning, context,
memory, thermal limits, battery and sustained quality. SmolLM3-3B is diagnostic,
not the approved final intelligence. Keep one or two general resident models at
most, plus specialist engines.

## OAI-03 Genuine model learning
Produce actual adapted neural weights or adapters through rights-cleared
owner-specific SFT, LoRA/QLoRA, preference optimization, curriculum training,
verified code/tool trajectories and other measured methods. No training on
unauthorized third-party proprietary outputs. Measure baseline against adapted
candidates on independent holdout; prevent forgetting and leakage. Model Laboratory
retains registry and promotion authority; no new competing training inventory.

## OAI-04 Primary offline Samsung host
The Samsung is the independently functioning local inference and action host.
Ordinary AI, memory and authorized local operations must work without PC or cloud
AI; Windows can augment builds, research and heavier processing, not become the
mandatory runtime. Benchmark actual CPU/GPU/NPU support; marketing claims are
not device tests, and pinned native-backend compatibility must be established.

## OAI-05 TeraBox extended storage
Use only the existing authorized Asterion TeraBox account/provider infrastructure,
not redundant authentication or bridges. Tier model archives, adapters, training
datasets, checkpoints, conversation histories, specifications, evidence and
generated artifacts, with versioned content identity, verified transfer,
resume, scoped encryption, quota, selective local cache and useful offline mode.
Cloud storage is not extra RAM, compute or guaranteed usable weight paging.

## OAI-06 Project-scale persistent cognition
Entire project histories can exceed one million tokens. Native context and
reasoning beyond the active context window must work through automatic,
source-linked retrieval, requirements ledgers, decision/supersession registers,
episodic/semantic/procedural/working memory, multi-hop reasoning, recursive
reconstruction, contradiction detection and exact source recovery. Never lose an
approved requirement because a summary or model context is bounded. Retrieval
must not depend exclusively on spontaneous model initiative.

## OAI-07 Owner methodology
The system learns to recover context and owner intent, execute authorized work,
resolve recoverable failures, avoid unnecessary questions and repeated bad
strategies, preserve all accepted functionality, test and verify before completion,
continue independent work during blockers, provide editable outputs and report
uncertainty without fabricated accomplishments. Apply both neural adaptation and
deterministic acceptance/recovery guarantees.

## OAI-08 Shared ecosystem ownership
Control owns central general reasoning, orchestration and verification; Nexus,
Core, Downloader, Rounder, Art, Sound, Game Pilot+Codex, KK, Elysium and other
specialists retain authoritative assets, databases, engines, workflows, model
specialization and independently usable functions. No duplication of services.
Protect all approved Nexus merge migrations and keep open decisions open.

## OAI-09 Complete assistant capability surface
Pursue high-quality reasoning, programming, architecture, math, research,
browsing/citations, coding, media/document understanding, multimodal generation
through original specialist engines, real files and editable artifacts,
spreadsheets, presentations, interactive controls, speech, dynamic UI,
automation, scheduled work and tool discovery without paid provider dependence.

## OAI-10 Durable autonomous improvement
Use the existing Control supervisor, backlog, verified executor and native WSS
to execute recovery→reconciliation→source inspection→planning→isolated edit→
functional tests→correction→regression→candidate commit→independent evidence→
next objective. Resume after crash, maintain idempotency, classify failures,
parallelize only independent work and never silently replay uncertain effects.
The model cannot edit protected verification or promote itself to production.

## OAI-11 L0–L4 learning
L0 immediate context; L1 persistent facts/corrections; L2 verified Skill Studio
procedures; L3 actual versioned neural adaptation; L4 continued pretraining,
distillation or compatible architecture evolution. Keep data rights, sealed
evaluation and rollback; no uncontrolled live weight updates.

## OAI-12 Distinct intelligence certification
Evaluate raw neural competence separately from adaptation, memory, long-context
reasoning, tool integration, complete assistance and autonomous continuity.
Measure actual owner-scale and representative unknown tasks, quality, instruction
intent, unnecessary clarification, false success, over-refusal, runtime,
RAM/thermal/battery and generalization. Preserve 50,000 unique sealed holdout,
200,000 distinct stress, 2,000 real integrated workflows and 1,000 independently
human-reviewed cases as maturity targets; never count synthetic mock success
as genuine certification.

## OAI-13 Preserved infrastructure and release hold
Preserve original Control signer, installed Android v0.9.38 until approved,
paired authenticated WSS, Windows worker/watchdog, GitHub fallback, app data,
M0–M13, approved R01–R08/R10 and B06/B09, legitimate Android permissions and
no redundant provider APIs. No premature interim APK or replacement worker;
final owner-signed release requires the approved acceptance gates.

## OAI-14 Architecture evidence and open decisions
Reconcile accessible 19-page Gemini, 54-page Claude, GPT-6.2 27-page document
plus JSON and Phone-First Intelligence V2. Treat proprietary architecture
inferences as unconfirmed and missing source sections as missing. No model-size,
NPU, storage-performance, paid-compute or migration proposals are automatically
approved merely because research recommended them.

## OAI-15 Parallel execution, not rigid sequencing
Advance architecture reconciliation, real inference, stronger model experiments,
device benchmarking, owner-specific data/training, project cognition, existing
TeraBox integration, autonomous recovery, ChatGPT-capability expansion and the
complete original Control/Nexus backlog concurrently where safe. Record actual
evidence and precise blockers; never wait on one independent workstream.
